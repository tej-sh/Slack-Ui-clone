# Slack UI Clone

A simple HTML/CSS mockup inspired by Slack.

This project is mainly a CSS practice exercise and is not meant to be a full, responsive clone for all screen sizes. It is just a small test to experiment with styling, layout, and UI structure.

## Overview

This repo tries to recreate the look and feel of Slack using only HTML and CSS. It focuses on the visual design and layout rather than full functionality.

## Features

- Sidebar navigation
- Chat header
- Message list
- Input area
- Slack-inspired color palette and spacing

## Run

Open `index.html` in your browser to view the project.

## Note

This is not built for every screen or device, and it is not a complete production-ready UI. It is only a basic CSS test and practice project.
